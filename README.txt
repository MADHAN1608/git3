BIRTHDAY SURPRISE — how to use
1. Unzip the folder and double-click index.html (works offline; fonts need internet, fallbacks are built in).
2. Add photos: put images in the /photos folder named photo1.jpg … photo6.jpg. They replace the placeholders automatically.
3. Change captions/emoji: edit the PHOTOS list near the top of script.js.
4. To share it: upload the whole folder to Netlify Drop / GitHub Pages and send her the link.
Music is a synthesised music-box "Happy Birthday" — it never autoplays; tap the 🎵 button.
